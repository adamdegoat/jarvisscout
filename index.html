⚙ How It Works · 7-stage autonomous pipeline
01
Discover
Scout scans quant literature, market data and competitor gaps nightly to surface new edge hypotheses.
→
02
Gauntlet
Every idea runs through 6 automated gates — score thresholds, proxy backtest, OOS holdout, multiple-testing penalty. Most ideas fail here. That's the point.
→
03
Generate
Surviving ideas get a complete trading bot auto-generated by Claude, filled with real strategy logic into a standardised scaffold.
→
04
Review
You review the generated code once. One approval per desk. Everything after is autonomous.
→
05
Incubate
The approved desk runs as a paper simulation using real market prices — no broker API needed. Simulated trades, real fees deducted, honest P&L.
→
06
Monitor
Daily decay detection tracks rolling win rate, Sharpe trend, and drawdown. Scout detects edge decay before it shows in P&L.
→
07
Retire → Learn
Retired desks generate autopsies. The learning engine builds a survival model: which strategy families produce durable edges, in which regimes, and why.
